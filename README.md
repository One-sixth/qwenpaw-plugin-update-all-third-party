# qwenpaw-plugin-update-all-third-party

QwenPaw 第三方插件一键更新插件。官方「全部更新」只覆盖官方插件，本插件把第三方的更新也补上。

## 使用

**入口**：QwenPaw 控制台 → 扩展 → 插件页 → **已安装插件**；或直达
`http://127.0.0.1:8088/market?tab=plugins`（端口按实际部署调整）。

页面工具栏会多出两个按钮：

- **检查第三方更新**——一键检查全部第三方插件（约 20~40 秒）。可更新的插件卡片顶部出现红色「可升级至 vX.X.X」横条，卡片上有「更新」按钮可单独更新。
- **更新全部第三方**——确认框列出所有「旧版本 → 新版本」，点「开始更新」逐个更新，完成后自动刷新页面。

更新为热重装，**无需重启 QwenPaw**。作者不一致的更新会先提示，人工确认后才会执行。官方插件走 QwenPaw 自带更新机制，本插件只管第三方。
